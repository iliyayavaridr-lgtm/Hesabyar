حساب‌یار ایلیا

این پوشه یک وب‌اپ نصب‌شونده (PWA) است.
امکانات:
- ثبت خرید، واریز و انتقال
- حساب‌های از پیش تعریف‌شده
- ذخیره محلی روی دستگاه
- ویرایش و حذف
- خروجی CSV برای Excel
- پشتیبان JSON

برای نصب واقعی روی آیفون:
1) فایل‌ها را روی یک هاست HTTPS مثل GitHub Pages، Netlify یا Cloudflare Pages منتشر کنید.
2) لینک را با Safari باز کنید.
3) Share > Add to Home Screen را بزنید.

نکته: من امکان انتشار مستقیم روی TestFlight یا امضای اپ iOS را ندارم؛ برای TestFlight باید پروژه Swift/Xcode، حساب Apple Developer و فرایند App Store Connect انجام شود.
